Data Hygiene Basics
Protect your dataset before sorting or filtering

Before sorting or filtering, your data must be "clean." Dirty data causes sorts to miss rows, filters to return wrong results, and formulas to break. Let's learn the golden rules.

💡

Golden Rules: (1) No blank rows or columns inside your data range. (2) Every column needs a unique header in Row 1. (3) One piece of data per cell — don't combine City + State. (4) Consistent formatting — don't mix "CA" and "California."

Multi-Column Sorting
Sort by multiple criteria while keeping rows intact

Google Sheets can sort by multiple columns at once. Go to Data → Sort range → Advanced range sorting options. Add columns in priority order. Critical: Always check "Data has header row" so headers don't get sorted into your data!

Task: You need to sort students by Grade (A→Z) first, then within each grade by GPA (Z→A, highest first). Put the sorting steps in the correct order.

4
Filter Views
Non-destructive filtering for collaborative spreadsheets

A Filter View (via Data → Filter views → Create new filter view) is personal and non-destructive. Other collaborators don't see your filter — they keep their own view. This is different from the basic Data → Create a filter toggle, which affects everyone.

Scenario: You and two colleagues share a roster of 500 students. You need to see only Grade 10 students, your colleague needs Grade 11, and another needs all grades. Which approach avoids disrupting each other?

💡

Pro tip: You can name your Filter Views (e.g., "Grade 10 Only") and switch between them from the Data → Filter views menu. They persist even after you close the sheet!

5
The SORT Function
Create a dynamic sorted copy of your data

The SORT function creates a live, sorted copy of your data in another location — without changing the original. Syntax:

=SORT(range, sort_column, is_ascending)

• range = the data to sort (e.g., A2:D20)
• sort_column = which column number to sort by (1 = first col, 2 = second, etc.)
• is_ascending = TRUE for A→Z / low→high, FALSE for Z→A / high→low

The FILTER Function
Extract rows that match specific criteria

The FILTER function returns only the rows that meet your condition. Syntax:

=FILTER(range, condition1, [condition2, ...])

• range = the data to return (e.g., A2:D20)
• condition1 = a boolean array like B2:B20=10 (Grade equals 10)
• You can chain multiple conditions with commas (AND logic)
