Restrictive Rule First Principle

Master rule ordering with drag-and-drop

🔒

📋 Mission Briefing

In Google Sheets, conditional formatting rules are applied top-to-bottom. The first matching rule wins! You must order the rules from most restrictive (specific) to least restrictive (general).

  • Score = 100 → Gold (most restrictive)
  • Score ≥ 90 → Green
  • Score ≥ 70 → Yellow
  • Score < 70 → Red (least restrictive)

Drag and drop the rules below into the correct order (most restrictive first)!

Custom Formula Row Highlighting

Use formulas with absolute references ($) for row-based rules

🔒

📋 Mission Briefing

To highlight an entire row based on one cell's value, you need a custom formula with the $ (dollar sign) for absolute column reference. For example, to highlight rows where column C = "Urgent":

=$C1="Urgent"

The $C locks the column to C, but the row number (1) changes for each row.
