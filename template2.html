Mission 3: Theme Customization

Objective: Customize built-in themes using the Google Slides theme panel and Theme Builder

Simulation: You want to customize a theme for your presentation. What is the correct sequence of actions?

Current step: 1/4

Step 1: Access Theme Options

Where do you find theme customization options in Google Slides?

Format → Text Color
Insert → Theme
Format → Themes
Tools → Preferences

Step 2: Choose Theme Colors

After selecting a theme, how do you customize the color scheme?

Click "Customize" in the theme panel and select "Colors"
Double-click on any text and change its color
Delete the theme and create a new one from scratch
Right-click on the slide and select "Change Background"

Step 3: Edit Master Slide

How do you access the Master Slide to make global layout changes?

View → Master
Insert → Layout
Format → Master Slide
Tools → Themes → Customize

Step 4: Apply Changes

After customizing your theme, how do you apply it to your presentation?

Click "Apply to All" in the theme panel
Close the theme panel and it will automatically apply
Manually apply to each slide individually
Save the theme as a template for future use
