🔧 Mission 1: System Requirements Checkpoint

A new employee needs several applications installed. Verify you know the system requirements to evaluate hardware readiness.

Quest 1 of 4 — 64-Bit Compatibility

📋 Service Ticket #1041: A technician is attempting to install a 64-bit financial database application on a workstation. The workstation has a 64-bit CPU but is running a 32-bit version of Windows 10.

What will happen?

✅ Correct! A 64-bit application requires both a 64-bit CPU and a 64-bit OS. The 32-bit OS cannot run it, even though the hardware supports 64-bit.
❌ Not quite. A 64-bit app needs both a 64-bit CPU and a 64-bit OS. WOW64 only helps 32-bit apps run on 64-bit platforms — not the other way around.

Quest 2 of 4 — File Path Knowledge

📋 Service Ticket #1042: You installed a 32-bit graphics utility on a 64-bit Windows 10 machine using default settings. A colleague asks where the application files are located.

Which directory contains the 32-bit application files?

✅ Correct! On 64-bit Windows, 32-bit applications install to Program Files (x86) by default, while 64-bit apps go into Program Files.
❌ On 64-bit Windows, 32-bit applications default to C:\Program Files (x86). The system32 and syswow64 folders store shared system DLLs/EXEs, not user applications.

Quest 3 of 4 — Hardware Requirements

📋 Service Ticket #1043: A user tries to launch a new 3D modeling application and receives this error: "RTX features are not available for this device. Please make sure you are running with a supported GPU and driver."

What is the most likely cause and best solution?

✅ Correct! The error specifically references GPU/driver support. Demanding applications like 3D modeling require a dedicated graphics card with its own video RAM, not integrated graphics.
❌ The error message points to GPU capability. This app requires a dedicated graphics card (with RTX features). Integrated graphics cannot meet this requirement.

Quest 4 of 4 — External Hardware Tokens

Some applications require more secure authentication than a simple password. What is an external hardware token?

✅ Correct! An external hardware token is a smart card or USB form-factor device storing cryptographic user ID data. The user must present the token and supply a password, PIN, or fingerprint.
❌ An external hardware token is specifically a smart card or USB device that stores cryptographic identification data. It requires both the physical token and a password/PIN/biometric to authenticate.

Quest 2 of 4 — Verifying Downloads

📋 Dispatch: A junior tech downloaded an application installer from a third-party website. Before installing it, what should be done to verify its authenticity?
✅ Correct! Windows uses digital signatures to verify publishers. Linux packages are verified by comparing a published hash value. Always scan for malware before installing.
❌ The proper verification method is to check the digital signature (Windows) or compare the hash value (Linux) and scan for malware. Relying on a single tool is not sufficient.

Quest 3 of 4 — Enterprise Deployment

📋 Dispatch: Your organization needs to deploy a new antivirus client to 500 workstations. Which method avoids requiring admin-level login on each client?
✅ Correct! GPO deployment runs the installer using a service account, so users don't need local admin privileges. This also allows scheduling deployments during off-peak hours to reduce network congestion.
❌ The best enterprise approach is Group Policy Objects (GPO). GPO can push installations remotely using a service account — no admin login needed on each client, and it can be scheduled for off-peak hours.

Quest 4 of 4 — ISO Files

An ISO file contains the contents of an optical disc in a single file. In Windows, how do you access an ISO file's contents?

✅ Correct! In Windows, right-click → Mount makes the ISO appear with the next available drive letter in File Explorer. ISOs are often used for complex installs like databases or VM OS setups.
❌ The correct method in Windows is to right-click the ISO and select Mount. It then appears as a virtual drive with the next available drive letter in File Explorer.

⚖️ Mission 3: Business Impact, Licensing & Security

Evaluate real-world scenarios involving the risks and responsibilities of deploying software in a corporate environment.

Quest 1 of 4 — Shadow IT

📋 Incident Report: Several employees have installed personal cloud storage apps on their work laptops without IT approval. The security team has flagged this as a risk.

This is an example of what concept, and why is it a risk?

✅ Correct! Shadow IT refers to unsanctioned software and devices deployed without IT oversight. It raises substantial operational and business risks including data leaks, compliance violations, and security threats.
❌ This is specifically Shadow IT — unsanctioned software/devices installed without IT department control. It raises substantial operational and business risks that go beyond any single concern like bandwidth or compatibility.

Quest 2 of 4 — Licensing Compliance

📋 Audit Alert: Your company purchased 50 single-device licenses for a financial application. During an audit, it's discovered the software is installed on 73 workstations.

What is the primary consequence?

✅ Correct! Installing unlicensed software exposes the company to financial and legal penalties. Commercial software must be used within the constraints of its license — whether that restricts device count or user count.
❌ Exceeding license limits is a serious compliance issue. It exposes the company to financial and legal penalties. Licenses restrict either the number of devices or users — violations have real consequences.

Quest 3 of 4 — Security Threats

When evaluating the security impact of installing new software, what is the principal threat from untrusted software?

✅ Correct! The Trojan Horse is identified as the principal threat — malware disguised as legitimate software. It can steal data or provide covert remote access. Always install from trusted, digitally signed sources and test in a lab first.
❌ The principal threat from untrusted software is a Trojan Horse — software whose true malicious purpose is concealed. It can steal data or enable covert remote access to the host or network.

Quest 4 of 4 — Deployment Considerations

📋 Planning Meeting: IT is scheduling a push deployment of a new application image to 200 desktops. The network admin warns about bandwidth impact.

What is the recommended scheduling approach?

✅ Correct! Pushing installations over the network causes congestion and increased latency. Organizations should limit deployments to non-critical times such as overnight or weekends to prevent disruptions.
❌ Network push deployments should be scheduled during non-critical times (overnight, weekends) to prevent network congestion and latency during normal business operations.

Quest 2 of 4 — Cloud Storage Sync

📋 User Call: An employee is traveling and using a mobile hotspot with limited data. OneDrive is consuming excessive bandwidth syncing files. What should you advise?
✅ Correct! Cloud storage apps allow you to pause or suspend synchronization, which is specifically helpful on metered connections where bandwidth is limited or data costs are higher.
❌ The best advice is to pause or suspend synchronization. This feature exists specifically for metered connections with limited bandwidth or increased monetary costs.

Quest 3 of 4 — Desktop vs. Web App

📋 User Call: An employee using Office 365 in the web browser cannot find an advanced formatting feature they need. What should you suggest?
✅ Correct! Cloud-based collaboration tools often have the option to switch to the desktop version. Some features are available only in the desktop application and not the web-based version.
❌ The solution is to switch to the desktop version. Web portal versions of Office 365 may lack some features that are available in the full desktop application.

Quest 4 of 4 — Collaboration Permissions

When installing collaboration tools like Teams, Slack, or Zoom, what hardware permissions typically need to be adjusted?

✅ Correct! Collaboration tools need permissions for file synchronization, webcam access, and microphone access to support their core functionality of video/audio calls and file sharing.
❌ Collaboration tools typically need permissions to access local files (for sync), the web camera, and microphone for video and audio calls.

🔑 Mission 5: Identity Synchronization & Licensing

Demonstrate your understanding of how identity providers and licensing work in cloud/on-premises hybrid environments.

Quest 1 of 4 — Single Sign-On Benefits

An organization uses a cloud-based identity provider synchronized with their on-premises Active Directory. What is the primary benefit for users?

✅ Correct! Identity synchronization allows a single set of credentials for both cloud and on-premises resources. This reduces the number of passwords users must remember and simplifies rights/permissions management.
❌ The primary benefit is a single set of credentials for both cloud and on-premises access. Passwords are still needed — but users only have to remember one set. It also simplifies IT permission management.

Quest 2 of 4 — Microsoft Entra Connect

📋 Architecture Review: The diagram shows On-premises AD connected to Microsoft Entra Connect, which synchronizes with Microsoft Entra ID in the cloud. The connection uses an AD DS Connector Account and a Microsoft Entra Connector Account.

What does this architecture accomplish?

✅ Correct! Microsoft Entra Connect synchronizes permissions, rights, and credentials between on-premises AD and cloud identity. This ensures the same control policies apply across both environments — a cohesive hybrid setup.
❌ Entra Connect synchronizes access policies, permissions, and credentials between on-premises AD and cloud. It doesn't replace AD — it ensures both environments stay in sync for a cohesive experience.

Quest 3 of 4 — Cross-Cloud Synchronization

Your organization uses both Google Cloud and Microsoft Azure. What does cross-cloud identity synchronization accomplish?

✅ Correct! Cross-cloud synchronization removes the need for separate credentials per provider. It reduces management and administrative burden when troubleshooting permission issues across cloud environments.
❌ Cross-cloud synchronization eliminates needing two separate sets of credentials and reduces the administrative burden for permission management and troubleshooting across cloud providers.

Quest 4 of 4 — Cloud License Management

📋 Admin Task: A new employee needs an Office 365 E3 license and a Power BI license assigned. An administrator discovers the wrong license type was assigned to another employee.

Where should cloud application licenses be managed and what should be done about the incorrect assignment?

✅ Correct! Licenses are managed through the Microsoft Entra admin center. If the wrong license is assigned, it should be corrected by changing the license or uninstalling and reinstalling with the correct one.
❌ Cloud licenses are managed via the Microsoft Entra admin center. Wrong assignments should be fixed by changing the license or doing an uninstall/reinstall with the correct license type.
